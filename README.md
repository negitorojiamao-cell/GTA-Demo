# NEON DISTRICT 3D

**BUILD 1.2 — GTA-inspired original 3D open-world prototype**

街・道路・車両・歩行者・警察・武器・ミッション・空港を備えた、Windows向けのオリジナル3Dオープンワールド試作です。GTA Vの雰囲気やジャンル要素を参考にしていますが、公式ゲームデータや公式マップを複製したものではありません。

## まず遊ぶ（Windows 10 / 11）

1. [最新版ZIP](https://github.com/negitorojiamao-cell/GTA-Demo/raw/main/GTA%20demo-20261107T013115Z-1-001.zip) をダウンロードします。
2. ZIPを右クリックし、**「すべて展開」**します。ZIPの中から直接起動しないでください。
3. 展開先の `NEON_DISTRICT` フォルダーを開き、`launch.bat` をダブルクリックします。
4. ブラウザーが開いたら、スタート画面でゲームを開始します。
5. 自動で開かない場合は、ブラウザーで **http://127.0.0.1:8765/** を開きます。
6. 終了時は起動した黒い画面で **Ctrl + C** を押します。

> `launch.bat`、`server.ps1`、`index.html`、`game.js`、`style.css` は同じフォルダーに置いてください。黒い画面はゲームの実行中は閉じないでください。

## 操作

| キー / 操作 | 動作 |
|---|---|
| W / ↑ | 前進 |
| S / ↓ | 後退 |
| A / ← | 左 |
| D / → | 右 |
| 画面をクリック | マウス視点を有効化 |
| マウス移動 | 視点回転 |
| 右マウスドラッグ | 視点回転（代替操作） |
| C | カメラを後方視点へ戻す |
| F長押し / 左クリック | 射撃 |
| 1〜4 / マウスホイール | 武器切り替え |
| TAB | 武器選択 |
| R | リロード |
| E | 車両・ヘリ・旅客機の乗降、対応建物の入退室など |
| SHIFT | 徒歩中のダッシュ／航空機の下降 |
| SPACE | 徒歩中の射撃入力／車内の急ブレーキ／航空機の上昇 |
| M | マップ・目的地選択 |
| H | 操作ガイド |
| ESC | 一時停止・メニューを閉じる |

### 旅客機

空港へ移動し、旅客機が着陸してターミナル付近で停止したら、機体に近づいて **E** で搭乗できます。操縦は **W** 加速、**S** 減速、**A / D** 旋回、**SPACE** 上昇、**SHIFT** 下降です。着陸して十分に減速した後、**E** で降機できます。

## 必要環境・通信

- Windows 10 / 11
- Windows PowerShell（Windows標準）
- WebGLに対応した最新のChrome / Edge / Firefox等
- **初回起動時のインターネット接続**（Three.jsをCDNから読み込みます）

ゲームサーバーは `127.0.0.1`（このPC自身）だけで待ち受けます。LANやインターネットへゲームサーバーを公開する設計ではありません。ゲーム内の3D描画はブラウザーとGPUで行います。

## 起動できないとき

1. ZIPをもう一度すべて展開し、必要ファイルが同じフォルダーにあるか確認します。
2. インターネット接続を確認します（Three.jsのCDN読み込みに必要です）。
3. `launch.bat` の黒い画面に表示されたエラーを確認します。
4. 展開先に作られる `launcher.log` を確認します。
5. ブラウザーで **F12 → Console** を開き、赤いエラーがあれば内容を確認します。
6. WebGLが無効、またはGPUドライバーが古い場合は、ブラウザーのハードウェアアクセラレーションとGPUドライバーを確認します。

詳しくは [トラブルシューティング](TROUBLESHOOTING.md) を参照してください。
