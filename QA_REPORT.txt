RENDERING / PERFORMANCE PASS
- Added conservative adaptive render resolution: the renderer samples average frame rate over 2.5-second windows and adjusts device pixel ratio gradually. It reduces resolution when measured frame rate falls below 50 FPS, reacts more strongly below 42 FPS, and slowly restores detail above 59 FPS. A cooldown prevents rapid oscillation. The upper DPR remains capped at 1.6 and the lower bound is 0.85 (or the device's native DPR when lower).
- Reduced the directional shadow map from 1536² to 1024² to reduce shadow rendering cost while retaining soft shadows.
- Removed redundant pixel-ratio resets on window resize; adaptive quality now owns render resolution.
- Kept the existing scene, lighting model, camera, world content, materials, gameplay and controls otherwise unchanged.

VALIDATION STATUS
- Changes are present on the improvement branch.
- Runtime GPU benchmarks and visual comparisons across integrated/discrete GPUs have not yet been performed. Adaptive thresholds are conservative starting values, not a claim of measured FPS gains on every device.


CITY ENVIRONMENT / ROAD SHAPE PASS
- Rebuilt road ribbons using centripetal Catmull-Rom resampling and smooth tangent-based cross sections. Road surfaces now follow continuous curves instead of connecting coarse control points with visibly angular trapezoids; lane dashes are placed along the resampled centerline.
