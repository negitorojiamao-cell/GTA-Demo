NEON DISTRICT 3D — BUILD 1.2
=============================

これはGTA Vの世界観・システムを参考にした、独自の3Dオープンワールド試作です。Rockstarの公式ゲームデータや公式マップを複製したものではありません。

【Windowsで起動】
1. ZIPを右クリックし「すべて展開」で、フォルダーごと展開します。
2. 展開した NEON_DISTRICT フォルダー内の launch.bat をダブルクリックします。
3. 黒いコンソールはゲーム終了まで閉じないでください。エラー時にも原因を読めるよう、終了前に pause します。
4. ブラウザーが自動で開かなければ http://127.0.0.1:8765/ を開きます。
5. 終了する場合はコンソールで Ctrl+C を押します。エラー詳細は launcher.log に記録されます。

【BUILD 1.1 から維持している修正】
- 左右旋回の入力方向を再修正し、A/←とD/→の向きを入れ替えて体感上の逆旋回を解消。前進・後退どちらでも左右入力は同じ。
- 橋の見える部分を道路幅と川幅・交差角に合わせて短くし、通常の道路に大きく張り出さないように調整。
- 車両・徒歩の通行許可は、見た目の橋とは別の細い「見えない通過領域」で管理。領域は橋と道路に沿い、橋のない川は引き続き通行不可。通過領域は障害物メッシュではないため、道路を物理的に塞がない。
- 建物の配置境界判定に回転後の幅・奥行きを反映し、市街地の端から角がはみ出す問題を修正。
- 建物同士の配置間隔を詰め、空白街区を埋める追加配置を増加。道路・川・ランドマークの予約領域は維持。
- 市街地外周の建物を境界から内側へ移動し、境界での不自然な切れ・重なりを抑制。
- 既存の高架高速道路、起伏のある地形、海岸・山道、空港、旅客機アニメーション、立体駐車場、屋上ヘリ、入室可能な建物、NPC・車両・警察・射撃を維持。
- 起動手順、必要ファイルの確認、起動失敗時のログ表示を含む launch.bat を同梱。

【操作】
W / ↑：前進・徒歩前進
S / ↓：後退・徒歩後退
A / ←：左旋回・徒歩左
D / →：右旋回・徒歩右
ゲーム画面をクリック：マウス視点を有効化（カーソル移動で視点回転）
右マウスドラッグ：マウス視点が使えない場合の代替操作
C：カメラを後方三人称視点へ戻す
F長押し / 左クリック：射撃
1〜4 / マウスホイール：武器切り替え
TAB：武器選択画面
R：リロード
E：車両の乗降、対応建物の入退室、駐車場リフト、ヘリ搭乗・降機、旅客機搭乗・降機
SHIFT：徒歩中のダッシュ／ヘリ下降／旅客機の機首下げ・下降
SPACE：徒歩中の射撃入力／車内では急ブレーキ／ヘリ上昇／旅客機の機首上げ・上昇
M：マップ・目的地選択
H：操作ガイド
ESC：一時停止／メニューを閉じる

【BUILD 1.2 追加仕様】
- 既存の街・道路・建物・NPC・車両・ミッション・警察・ヘリ・既存の旅客機ルートを維持し、操作できる旅客機を追加。
- 空港の既存旅客機は着陸後にターミナル付近まで走行し、ゲートで30秒間停止。停止中はHUDに搭乗可能表示と出発までの残り秒数を表示し、機体近くでEを押すと搭乗できる。
- 搭乗すると旅客機の自動飛行ルートから操作を引き継ぎ、Wで加速、Sで減速、A/Dで旋回、Spaceで機首を上げて上昇、Shiftで機首を下げて下降。
- 旅客機は地上・滑走路へ着陸して十分に減速した後、Eで降機可能。降機した機体はその位置に駐機する。
- マウス視点操作を追加。ゲーム画面をクリックすると相対マウス移動で視点を回転できる。ブラウザーのポインターロックが使えない場合は右ドラッグが代替となる。Cで後方視点へ戻せる。

【必要環境】
- Windows 10/11、Windows PowerShell、WebGL対応ブラウザー
- Three.jsをCDNから読み込むため、初回起動時はインターネット接続が必要
- 同梱ファイル（launch.bat / server.ps1 / index.html / game.js / style.css）は同じフォルダーに置く

【機能範囲について】
本ビルドに実装済みの機能と、今後の拡張仕様として文書化された機能は DESIGN_SPEC.md に区別して記載しています。GTA V本編の全ミッション、完全な3主人公切り替え、LCN/BAWSAQの完全再現、テレビ番組の全スケジュールなどを完全実装したものではありません。

【検証について】
- JavaScript構文検査（node --check）に合格
- ZIPアーカイブ整合性検査（unzip -t）を実施
- HTMLのローカル配信確認を試行
- この実行環境ではWindows上の実プレイを完全再現できないため、全PCで「エラーが一切出ない」とは保証できません。WebGL、CDN接続、GPUドライバーの影響は実機で最終確認してください。
